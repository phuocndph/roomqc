## 1. Hợp đồng đo và phục hồi

Mỗi run khóa source snapshot, migration chain, release fixture, DB identities, role graph và budget trước khi chạy. Dùng database/container/volume/network riêng có ownership; secrets chỉ ở file private. Kiểm11 bảng nghiệp vụ, authority, management, credentials, commands/audit; ghi command count, credential ID, version, DB expiry/revocation, file hash/mode/inode, barrier quan sát được, terminal exit và cleanup. Không ghi DSN, bearer hoặc signer vào output công khai.

**CLI chết không đồng nghĩa SQL đã rollback.** Autocommit statement ở server có thể tiếp tục sau khi client mất kết nối. Với ca trước commit: quan sát đúng barrier và outcome DB thực tế sau khi statement kết thúc; outcome chưa xác định phải giữ unknown. Sau restart dùng đúng caller/key/body, cho phép hoàn tất command chưa commit hoặc nhận lại receipt đã commit, tổng effect của command luôn bằng1. Nếu bài thử cố ý cancel backend/rollback transaction để chứng minh zero effects, ghi đó là một can thiệp riêng; không suy ra từ SIGKILL client.

Không sửa expiry/authority thành hợp lệ chỉ để replay qua. Nếu receipt đã hết hạn hoặc target bị rút quyền, expected là dừng publication/readiness và chuyển đối soát, không phải tự cấp mới. Các input hoặc effect ngoài scope làm test fail; timeout test không là terminal proof của tiến trình bị thử.
